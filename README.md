# medical


💊 Clinix - Medical Store Billing Software

**WELCOME TO MEDICAL SOFTWARE**
Ye mera Python me bana hua Medical Store ka Billing Software hai. Is me dawai ka naam likho, quantity likho, ye khud-ba-khud poora bill bana dega.

Developed by **Rana Abdul Wahab**

✨ Features
- 50+ Medicines aur Medical Items pehle se saved hain
- Customer se item ka naam le kar uski price khud nikalta hai
- Quantity se Total khud calculate karta hai
- Agar item available na ho to "Sorry, Ya Item Available Nhi Ha" likhta hai
- Aakhir me poora saaf-suthra Bill print karta hai
- Bukhari Pharmacy ka naam, address aur Drug License No. ke saath

🗂️ Categories
- **Bukhar / Dard:** Panadol, Brufen, Disprin, Ponstan, Calpol
- **Pet / Maida:** Eno, Gaviscon, Risek, Flygel
- **Nazla / Khansi:** Arinac, Corex, Hydryllin, Vicks
- **Antibiotic:** Azomax, Augmentin, Velosef
- **Diabetes / BP:** Glucophage, Getryl, Lowplat, Inderal
- **Vitamins:** Surbex Z, Osnate D, CaC 1000, Evion
- **Bachon ki Dawai:** Gravinate, Domel, Colic Drops
- **Medical Cheezen:** Thermometer, BP Apparatus, Bandage, Dettol, Glucometer, Nebulizer, Wheel Chair, Diapers

🚀 Kaise Chalayen (How to Run)
1. Python install karein
2. File ko download karein medical_store.py
3. Terminal / CMD me ye likhein: python medical_store.py
